USER AUTHENTICATION FLOW:
================================================================================

SIGNUP FLOW:
------------
User Input (Email/Password)
        │
        ├─► Validate Input (Frontend)
        │
        ├─► POST /api/signup
        │       │
        │       ├─► Check if email exists
        │       │
        │       ├─► Hash password (bcrypt)
        │       │       salt rounds = 10
        │       │
        │       ├─► Create User document
        │       │       {userName, email, password, imageUrl}
        │       │
        │       ├─► Create UserData document
        │       │       {favourites: [], playlists: [], songHistory: []}
        │       │
        │       ├─► Link UserData to User
        │       │
        │       ├─► Generate JWT Token
        │       │       payload: {email, id}
        │       │       secret: process.env.JWT_SECRET
        │       │       expiry: 30 days
        │       │
        │       └─► Set HTTP-only Cookie
        │               name: "token"
        │               maxAge: 30 days
        │
        └─► Redirect to Home Page


LOGIN FLOW:
-----------
User Input (Email/Password)
        │
        ├─► POST /api/login
        │       │
        │       ├─► Find user by email
        │       │
        │       ├─► Compare passwords
        │       │       bcrypt.compare(inputPassword, hashedPassword)
        │       │
        │       ├─► Generate JWT Token
        │       │
        │       └─► Set HTTP-only Cookie
        │
        └─► Redirect to Home

PLAYLIST MANAGEMENT FLOW:
================================================================================

CREATE PLAYLIST:
----------------
User clicks "Create Playlist" button
        │
        ├─► Modal opens with input field
        │
        ├─► User enters playlist name
        │
        ├─► POST /api/userPlaylists
        │       body: {name: "My Playlist"}
        │       │
        │       ├─► Verify JWT token from cookie
        │       │
        │       ├─► Get user ID from token
        │       │
        │       ├─► Create Playlist document:
        │       │       {
        │       │         name: "My Playlist",
        │       │         songs: [],
        │       │         user: userId,
        │       │         createdAt: Date.now()
        │       │       }
        │       │
        │       ├─► Push playlist ID to UserData.playlists[]
        │       │
        │       └─► Return: {success: true, data: playlist}
        │
        ├─► Update Redux state (add playlist)
        │
        ├─► Show success toast
        │
        └─► Playlist appears in sidebar


ADD SONG TO PLAYLIST:
---------------------
User clicks "+" icon on song → "Add to Playlist"
        │
        ├─► Modal shows user's playlists
        │
        ├─► User selects playlist
        │
        ├─► POST /api/userPlaylists/songs
        │       body: {
        │         playlistID: "playlist_id",
        │         song: {full song object with metadata}
        │       }
        │       │
        │       ├─► Verify JWT token
        │       │
        │       ├─► Find playlist by ID
        │       │
        │       ├─► Check if song already exists
        │       │
        │       ├─► If not, push song to playlist.songs[]
        │       │
        │       ├─► Save playlist
        │       │
        │       └─► Return: {success: true, message: "Song added"}
        │
        ├─► Show success toast: "Added to {playlist name}"
        │
        └─► Modal closes


REMOVE SONG FROM PLAYLIST:
--------------------------
User clicks "X" icon on song in playlist view
        │
        ├─► DELETE /api/userPlaylists/songs
        │       body: {playlistID: "...", song: {id: "..."}}
        │       │
        │       ├─► Verify JWT token
        │       │
        │       ├─► Find playlist
        │       │
        │       ├─► Filter out song: playlist.songs.filter(s => s.id !== songId)
        │       │
        │       ├─► Save updated playlist
        │       │
        │       └─► Return: {success: true}
        │
        ├─► Update UI (remove song from list)
        │
        └─► Show toast: "Removed from playlist"


DELETE PLAYLIST:
----------------
User clicks delete icon on playlist
        │
        ├─► Confirm modal: "Are you sure?"
        │
        ├─► User confirms
        │
        ├─► DELETE /api/userPlaylists
        │       body: {playlistId: "..."}
        │       │
        │       ├─► Verify JWT token
        │       │
        │       ├─► Find and delete Playlist document
        │       │
        │       ├─► Remove playlist ID from UserData.playlists[]
        │       │
        │       └─► Return: {success: true}
        │
        ├─► Update Redux state
        │
        └─► Playlist removed from sidebar

LYRICS FETCHING FLOW:
================================================================================

User clicks "Lyrics" button on player
        │
        ├─► getlyricsData(songName)
        │       │
        │       ├─► Try Source 1: Musixmatch
        │       │       │
        │       │       ├─► Build URL:
        │       │       │   "https://lyrics.lewdhutao.my.eu.org/v2/musixmatch/lyrics?title={songName}"
        │       │       │
        │       │       ├─► Proxy through AllOrigins (bypass CORS):
        │       │       │   "https://api.allorigins.win/get?url={encodedLyricsUrl}"
        │       │       │
        │       │       ├─► Fetch response
        │       │       │
        │       │       ├─► Parse JSON: JSON.parse(response.contents)
        │       │       │
        │       │       ├─► Validate: lyrics exist and not empty
        │       │       │
        │       │       └─► If valid: return {success: true, data: lyrics}
        │       │
        │       ├─► If Source 1 fails, Try Source 2: YouTube
        │       │       │
        │       │       ├─► Same proxy process
        │       │       │
        │       │       └─► Return if valid
        │       │
        │       └─► If both fail: return {success: false}
        │
        ├─► If success:
        │       Display lyrics in scrollable modal/panel
        │       Lyrics auto-scroll (optional)
        │
        └─► If fail:
                Display: "Lyrics not available for this song"

REDUX STATE FLOW:
================================================================================

USER ACTIONS → REDUX ACTIONS → REDUCERS → STATE UPDATE → UI RE-RENDER

Example: Playing a Song
------------------------
1. User clicks song
        ↓
2. Dispatch: setActiveSong({song, data, i})
        ↓
3. playerSlice reducer updates state:
        {
          activeSong: songObject,
          currentSongs: arrayOfSongs,
          currentIndex: i,
          isActive: true,
          isPlaying: true
        }
        ↓
4. Redux Persist saves to localStorage
        ↓
5. useSelector hooks in components get updated state
        ↓
6. MusicPlayer component re-renders with new song
        ↓
7. <audio> element src updates
        ↓
8. Song plays

SECURITY FLOW:
================================================================================

PASSWORD HASHING:
-----------------
User signs up with password: "mypassword123"
        │
        ├─► bcrypt.hash("mypassword123", 10)
        │       salt rounds = 10 (2^10 iterations)
        │       │
        │       └─► Hashed: "$2a$10$abcdefg..."
        │
        ├─► Store in DB: {password: "$2a$10$abcdefg..."}
        │
        └─► Login:
                bcrypt.compare(inputPassword, storedHash)
                Returns: true/false


JWT FLOW:
---------
User authenticates
        │
        ├─► Server generates token:
        │       Jwt.sign(
        │         {email: "user@example.com", id: "user_id"},
        │         process.env.JWT_SECRET,
